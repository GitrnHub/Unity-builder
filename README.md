# Cloud Wander Demo

A tiny Unity project designed to be generated and built entirely in the cloud.

## Controls

- WASD: move
- Space / E: up
- Left Ctrl / Q: down
- Left Shift: speed boost
- Hold right mouse button and drag: look
- Arrow keys: look

The scene is generated automatically by `Assets/Editor/CloudProjectBootstrap.cs` when Unity imports the project. No local Unity Editor is required to author the initial scene.
